# Bank Account Management System

## Description

A simple PHP Object-Oriented Programming project that simulates basic bank account operations.

## Features

- Create bank accounts
- Deposit money
- Withdraw money
- Check balance
- Display account details
- Validate transactions

## OOP Concepts Used

- Classes and Objects
- Constructor
- Encapsulation
- Access Modifiers
- Methods
- Type Declarations

## How to Run

php index.php

------
>When running in localhost to get newline break use the `<br>`.
